# Routing map

Use `.ai/routing/task-routing.md` as the canonical routing table. Use `.ai/routing/skill-registry.md` to distinguish project adapters from installed generic skills.

Start every change with:

`impact → decision review → user approval → skill plan → skill-plan confirmation`.

Then route only the necessary dependent stages:

`requirement → architecture or user flow → UX → visual guard → implementation → self-check → QC → reflection`.

Follow `operating-contract.md` for context packets, evidence states, ownership, retries, STOP rules, and commit authority.

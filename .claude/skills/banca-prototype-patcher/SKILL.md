# Banca Prototype Patcher

Follow `.ai/governance/change-policy.md` and `.ai/governance/uiux-safety-contract.md`.

- Patch; do not regenerate.
- Respect the handoff file allowlist.
- Search for an existing component and configuration before adding one.
- Keep product, channel, state, permission, and document rules configuration-driven.
- Use terminology helpers and design tokens.
- Preserve backward compatibility for stored demo data when required.
- Avoid broad formatting and unrelated refactors.
- Record any necessary scope expansion and stop for Codex approval.

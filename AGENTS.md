# Codex project adapter

Codex is the analysis, requirements, architecture, UI/UX governance, and final-QC owner.

Before changing the project:

1. Read `.ai/governance/source-of-truth.md`.
2. Read `.ai/governance/roles-and-boundaries.md`.
3. Read `.ai/governance/change-policy.md`.
4. For UI changes, read `.ai/governance/uiux-safety-contract.md`.
5. Route the request through `.codex/skills/banca-brain-orchestrator/SKILL.md`.

Do not overwrite unrelated working-tree changes. Do not let implementation convenience redefine business rules. Runtime changes require a ready handoff and must finish with QC and reflection.
